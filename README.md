# IS218 Game AI Lab

A shared research notebook for testing AI-assisted gameplay programming, audio, and 3D asset creation. The first experiments use a locked door to compare generated outputs in the same playable scene.

[Open the research site](https://ms543-create.github.io/is218-game-ai-lab/)

## Contribute

Run `npm ci` and `npm run docs:dev` to preview changes. Start with [the experiment briefs](docs/experiments.md), then use [the field notes template](docs/field-notes.md) to document a run. Run `npm run docs:build` before pushing. Changes on `main` deploy to GitHub Pages.
